# Data Structures Implementations

This repository contains implementations of fundamental data structures in C++.

## Data Structures Included
- **Arrays**: Basic operations and examples (see `arrays/`).
- **Linked Lists**: Singly and doubly linked list implementations (see `linked_lists/`).
- **Stacks**: Stack using dynamic arrays (see `stacks/`).
- **Queues**: Queue using arrays and simple queue (see `queues/`).
- **Binary Search Tree**: Basic BST operations (see `binary_search_tree/`).
- **Bank Management System**: A simple system using data structures (see `bank_management_system/`).

## How to Use
1. Clone the repository: git clone https://github.com/abdelRahmaneLsafty75/Data-Structures-Implementations.git
2. Navigate to the desired folder (e.g., `arrays/`).
3. Compile and run the C++ files using a compiler like `g++`:g++ array_operations.cpp -o array_operations ./array_operations
